# Agent Instructions

## Regra Obrigatória: Commit e Push

Toda alteração feita no código DEVE ser commitada e enviada (push) imediatamente.

- **Antes de terminar uma tarefa**, sempre rodar:
  ```
  git add -A
  git commit -m "descrição da alteração"
  git push
  ```
- Nunca deixar alterações pendentes sem commit.
- Mensagens de commit devem ser claras e descritivas em português ou inglês.
